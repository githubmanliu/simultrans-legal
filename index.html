离线同传官 隐私政策

生效日期：2026 年 11 月 20 日

离线同传官是一款在 iPad 与 Mac 上运行的中英日韩同声传译 App。对着会议、演讲、聊天录音，屏幕实时显示双语字幕，并整理成会议记录。

说在前面最重要的一句：你的音频永远只留在你的设备里。 语音识别和翻译默认全部在你的设备上完成，不联网也能用，没有账号，没有我们的服务器。

一、我们收集什么信息

默认情况（免费版、¥18 不限时版、以及未开启云增强的所有情况）

我们不收集任何个人信息：

  • 没有账号，不需要注册或登录，不要求邮箱、手机号、姓名。
  • 没有广告，没有第三方广告 SDK。
  • 没有埋点统计和行为分析。
  • 没有崩溃上报，没有设备指纹。
  • 不读取通讯录、位置、相机、相册、日历。

App 唯一需要你授权的是麦克风。按下录音键时，App 从麦克风读取实时音频流。音频只存在于设备内存和 App 沙盒里，不会离开这台设备。

使用「云增强」时（订阅版 / 全买断版）

云增强是可选功能，默认关闭，需要你自己配置一个大模型服务。开启后：

  • **发送的内容**：只有**翻译后的文字**（以及你填写的会议背景与术语表、最近几段上文）。**音频永远不发送。**
  • **发送给谁**：发送到**你自己填写的**那个服务地址（可以是 DeepSeek、通义、智谱等云端服务，也可以是你自己在局域网里跑的 llama.cpp / LM Studio / Ollama）。这个地址由你决定，不是我们。
  • **谁付款**：模型服务由你自己提供，我们不经手、不代付、不存储你的 API Key（存在你设备的系统钥匙串里）。
  • **我们不中转**：请求从你的设备直接发往你配置的服务，不经过我们的任何服务器。

    • 如果你从来不开云增强，这个 App 一个字节都不会发到网络上。

    二、信息如何被使用

    App 只在本地使用麦克风音频，做三件事：识别成文字、翻译成另一种语言、显示成字幕。会议记录保存在你的设备上，供你自己查看和导出。

    我们不查看、不分析这些内容——因为它们从没到过我们这里。

    三、数据存储在哪里

  • **录音和会议记录**：保存在 App 自己的沙盒目录里，只在你的设备上。
  • **导出的文件**：由你决定存到哪里、通过谁分享。App 不会主动往外发。
  • **模型文件**：语音识别与翻译模型（约 2.6 GB）随 App 一起安装在本机，**首次打开不会再下载**，也不需要联网。
  • **API Key**（仅云增强）：存在你设备的系统钥匙串（Keychain）里。
  • **购买记录**：由 Apple 的 App Store 系统管理，我们无法读取你的支付信息。

    • App 不做任何服务器备份。这些数据不在我们手上，我们也无法替你保管或恢复——删掉了就是删掉了。

    四、我们不会做什么

  • 不上传麦克风音频。
  • 不联网传输你的录音、记录、字幕或翻译结果（云增强只发译文文本，且由你主动开启）。
  • 不把任何内容用于训练模型。
  • 不出售、不交换、不分享你的数据——我们手上也没有。
  • 不做广告，不做用户画像。

    • 五、麦克风权限说明

    App 请求麦克风权限，用于在你按下录音键时接收现场语音并实时转成文字和字幕。

  • 权限只在录音期间生效，停止录音后不再使用麦克风。
  • 不录音的时候，App 不会启动麦克风。
  • 音频不会写进云端，也不会同步到其他设备。
  • 拒绝权限的话，App 仍然可以打开，只是无法开始转写。

    • App 还会调用系统的语音识别能力作为辅助。识别过程同样在本机完成，音频不会因此被上传。

    • 七、第三方组件

    App 内置的 AI 组件（Qwen3-ASR 用于识别，Hy-MT2 用于翻译）以及运行它们的推理框架，都随包发布在你的设备上，全部离线运行。

    第三方开源组件（llama.cpp、Silero VAD、ONNX Runtime 等）遵循各自的开源许可证。

    八、儿童隐私

    离线同传官是一个会议工具，不面向儿童设计，也不收集任何人的信息。我们不建立用户画像，儿童使用本 App 不会产生需要收集的数据。

    如果有家长对孩子的使用有疑问，请通过下面的邮箱联系我们。

    九、你的权利

    因为数据都在你的设备上，控制权也在你手上：

  • **查看**：在 App 内随时查看所有记录。
  • **导出**：随时导出为文本或文档，保存到你自己的位置。
  • **删除**：随时在 App 内删除单条或全部记录，也可以直接删除 App——沙盒目录会随之一起清除。
  • **撤回权限**：在「设置 → 隐私与安全性 → 麦克风」里随时关闭麦克风访问。
  • **删除 API Key**：在 App 的模型管理里点删除，钥匙串里的记录会一并清除。

    • 我们不会主动联系你，也不会因为你行使这些权利而区别对待——因为你从来没把数据交给过我们。
